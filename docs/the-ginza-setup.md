# THE GINZA ページ設定

対象はブランドTOP・カテゴリ／全商品一覧・ストーリー・サイトTOPのブランド入口。商品詳細テンプレートと購入処理は既存仕様を使用する。

## テンプレートと商品データ

- ブランドコレクションの推奨ハンドルは `the-ginza`。公開対象の「ザ・ギンザ」商品のみを所属させ、`collection.the-ginza` を割り当てる。
- 商品登録・タグ付け・公開は別のストア側作業。この実装では商品を登録しない。商品詳細には既存の商品テンプレートを使う。
- 分類タグは `スキンケア`／`プロテクション`／`ボディ`／`フレグランス`／`セット・その他`。商品カタログのBO列「申し送り事項」に従い、原則として各商品に1つを設定する。カテゴリのキーとタグは固定の組み合わせとし、テーマエディタで商品タグは変更できない。33品の内訳は18／3／4／2／6。
- カテゴリURLは `/collections/the-ginza/スキンケア?view=the-ginza-products` の形式。日本語のタグはShopifyのハンドル形式で生成する。
- 全商品一覧は `/collections/the-ginza?view=the-ginza-products`。48品単位でページ分割し、各ページ内を上記カテゴリ順に区切る。商品はコレクションの掲載順（または選択した並び替え順）を各カテゴリ内で維持する。
- 複数カテゴリに一致する商品は上記順の最初のカテゴリに1回表示する。分類タグがない商品も「その他の商品」に表示し、取りこぼさない。分類漏れは公開前に修正する。
- 商品カードは メーカーが `THE GINZA` または `ザ・ギンザ` の商品だけを描画する。空のカテゴリは全商品一覧では表示しない。空の一覧には商品未検出メッセージを表示する。

## 共通メタフィールド

ブランドコレクションに設定する。Sukiyaオンラインのテストストアでは `my_fields.brand_top_logo` の定義が既存。画像は画像ファイルを指定し、未設定時は同梱ロゴを使用する。ストーリーページでは同じコレクションをセクションで選択する。

以下のコレクション定義を管理画面で作成し、対象コレクションに値を入力する。既存定義がある場合は名前空間・キー・型を確認して再利用する。

| 名前空間・キー | 型 | 用途 |
| --- | --- | --- |
| `my_fields.brand_top_logo` | `file_reference` | ロゴ（既存定義） |
| `custom.the_ginza_story_page` | `page_reference` | 公開済みストーリーページ |
| `custom.the_ginza_category_image_<キー>` | `file_reference` | カテゴリ画像 |
| `custom.the_ginza_category_description_<キー>` | `rich_text_field` | カテゴリ説明 |

カテゴリのキーは `skincare`、`protection`、`body`、`fragrance`、`sets`。それぞれ画像・説明の定義を作成する（例：`custom.the_ginza_category_image_skincare`）。画像はTOPとカテゴリページで共通。未設定の説明は表示しない。定義と値はストアごとに必要であり、テーマのデプロイだけでは作成されない。

## ブランドTOP

1. `THE GINZA ブランド` セクションのBEST SELLERとNEW ARRIVALSにそれぞれ4品を表示順に選択する。未選択の枠は非表示。他ブランド商品は表示対象外。
2. 初期BEST SELLERはジェルオイル n、ローション n、エマルジョン n、トライアルキット n。NEW ARRIVALSはホリデー2種、リバイタライザー n、マスク スペシャルキット。商品は実際の登録情報を確認してから選ぶ。
3. 支給ロゴとページ用画像をテーマアセットに同梱済み。共通のロゴ・ストーリーリンク・カテゴリ画像と説明は下記のコレクションメタフィールドで管理する。未設定の画像は同梱アセットを表示する。
4. PC・SPのKV採用案が未確定のため、`確定したKVを表示` は初期OFF。画像の候補を選択し、代替テキスト・リンク先を確定してからONにする。SPは正方形／縦長、PCは正方形／横長を選べる。
5. KV直下紹介、CLOSE UPコピー、ブランド紹介本文、店舗案内は確定原稿だけを設定する。カテゴリ説明はコレクションの共通メタフィールドに設定する。本文空欄は非表示。
6. CLOSE UPのうちスペシャルケアは訴求商品・画像・リンクの整合が未確定のため初期OFF。他3枠のリンクも未確定時はリンクなしで描画する。
7. ストーリーページを作成・公開した後にコレクションのストーリーページ参照に設定する。未設定時にストーリーへのリンクは生成しない。

## ストーリー

- ページを作成し、`page.the-ginza-story` を割り当てる。ブランドコレクションを選択する。
- 支給静止画はKV → 1975 → 2002 → 美学 → 2025の順で設定済み。各章の見出し・本文は確定稿がないため空欄。PPTの省略文やWeb上の文章は補完していない。
- 商品紹介はローション／ジェルオイル／エマルジョンの3品を商品ピッカーで設定する。動画・スクロール演出・指定Webフォントは保留。
- 各章の本文が未設定の段階では制作途中のページ。公開には確定全文とブランド側確認が必要。

## 共通導線

- サイトTOPの `TOP BRAND LIST` にTHE GINZAのコレクション選択と表示スイッチを追加。初期OFF。公開準備が整ってからコレクションを指定して有効にする。
- 正方形ロゴは横長の枠内に切り抜かず表示する。
- グローバルヘッダのブランドメニューはShopifyのナビゲーションデータで管理されるため、公開時に管理画面からリンクを追加する。既存メニューデータをこの変更では書き換えない。
- ブランド内のカテゴリ／ストーリー導線は専用ヘッダとSPの閉じたブランドメニューから提供する。未確定のLINE導線は追加していない。

## 保留事項と公開前確認

KVの採用サイズとリンク、紹介・ストーリー等の確定全文、店舗情報とLINE、スペシャルケアの選品・遷移先、Brand Guideline v2.1原本とロゴ余白、Webフォント・動画・演出、カテゴリ内の商品順を確認する。

元資料は2026/10/6版の構成案v3、商品カタログ1006、ページ素材一覧。商品詳細の全成分等の補完と月次売上提出の仕様は別作業。

## 検証

- `npm run build`
- `npm test -- --runInBand test/the-ginza.test.js`
- `shopify theme check`（既存の指摘と変更ファイルの指摘を区別する）
- テスト環境でブランドTOP・5カテゴリ・全商品一覧・ストーリーをPC/SPで確認。33品の画像・価格・分類・商品リンク、未設定枠の非表示、ブランド入口の公開スイッチを確認する。
- LiquidJSのテストはLiquidテンプレートをフィクスチャで描画する。Shopify固有の画像／翻訳フィルタとページ分割済みコレクションは模擬するため、実ストアのタグルーティング・ページ分割・商品データを保証しない。
- 静的プレビューはレイアウト確認用。Shopifyへのテーマアップロード、ページ／コレクションへの割り当て、商品登録・公開の確認とは分けて記録する。
